# Yummy TV — приложение для Android TV (и телефонов)

Просмотр аниме через API YummyAnime (api.yani.tv): главная («Продолжить просмотр» и аниме текущего сезона),
каталог с поиском, Топ-100 (сериалы / фильмы / ONA), случайное аниме, страница аниме с выбором плеера, озвучки
и серии в выезжающих меню, «Порядок просмотра» (все части франшизы списком), отметки просмотренных серий, аккаунт со списками «Смотрю / В планах / Просмотрено / Отложено / Брошено / Любимые».

## Перед сборкой
Откройте файл `app/src/main/java/app/yummytv/Config.kt` и вместо `PASTE_YOUR_TOKEN_HERE`
вставьте токен приложения со страницы https://yummyani.me/dev/applications

## Сборка APK на GitHub
1. Загрузите все файлы проекта в новый репозиторий на github.com.
2. Откройте вкладку **Actions** → дождитесь зелёной галочки у «Build APK».
3. Откройте этот запуск и внизу, в разделе **Artifacts**, скачайте `YummyTV-apk` (zip с файлом `app-release.apk`).

## Дизайн
Тёмная тема с градиентами, большой баннер на главной, градиентная рамка и увеличение при фокусе, мерцающие заглушки при загрузке. Общие элементы — в `Design.kt` и `Ui.kt`.

## Плеер
* По умолчанию выбирается Alloha (стандартное управление пультом).
* Kodik: ОК — пауза, ▲ — курсор-«мышка», ▼ — перемотка на 90 сек.
* В обоих плеерах: кнопка «Меню» или удержание ▲ — выдвижное меню выбора серии.
