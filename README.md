# Yummy TV — приложение для Android TV (и телефонов)

Просмотр аниме через API YummyAnime (api.yani.tv): главная (новые серии, расписание, новинки),
поиск, страница аниме с выбором озвучки и серии, вход в аккаунт, списки «Смотрю / В планах / Просмотрено…».

## Перед сборкой
Откройте файл `app/src/main/java/app/yummytv/Config.kt` и вместо `PASTE_YOUR_TOKEN_HERE`
вставьте токен приложения со страницы https://yummyani.me/dev/applications

## Сборка APK на GitHub
1. Загрузите все файлы проекта в новый репозиторий на github.com.
2. Откройте вкладку **Actions** → дождитесь зелёной галочки у «Build APK».
3. Откройте этот запуск и внизу, в разделе **Artifacts**, скачайте `YummyTV-apk` (zip с файлом `app-debug.apk`).
